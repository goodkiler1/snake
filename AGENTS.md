# Змейка

Игра в браузере. Весь код — в одном файле `index.html`: разметка, стили и логика.

**Живая версия:** https://goodkiler1.github.io/snake/

## Правила проекта

- **Один файл, никаких зависимостей.** Ни библиотек, ни сборки, ни npm.
  Файл должен открываться двойным щелчком и работать без интернета.
- **Отрисовка на `<canvas>`**, поле 20×20 клеток по 20 пикселей.
- **Телефон равен компьютеру по важности.** Свайпы, экранные кнопки, поле
  подстраивается под высоту экрана, страница не прокручивается во время игры.

## Как проверять изменения

Открывать через локальный сервер, а не по `file://`:

```powershell
python -m http.server 8140 --directory C:\Users\PC-01\projects\snake
```

Проверять обязательно оба размера — обычный и мобильный (375×812).

**Осторожно с кешем:** браузер держит старую версию. Если правки не видно,
добавь `?v=2` к адресу.

**Синтетические клики в панели браузера не дают `pointerdown`** — экранные кнопки
на них не реагируют, хотя на телефоне работают. Проверяй логику через консоль,
а не кликами.

## Деплой

```
git add -A
git commit -m "что изменил"
git push
```

GitHub Pages пересобирает страницу примерно за минуту.

## Стиль кода

Константы вынесены наверх файла: скорость, размер поля, шаг ускорения.
Комментарии по-русски и только там, где логика неочевидна.
