# Змейка

Классическая «Змейка» в браузере. Один файл, без библиотек и установки.

**Играть:** https://goodkiler1.github.io/snake/

## Управление

| Клавиши | Действие |
|---|---|
| `←` `↑` `↓` `→` или `WASD` | движение |
| `Пробел` | пауза и продолжение |

На телефоне — свайпы по полю.

## Правила

Собирай красные яблоки: за каждое змейка растёт, а игра немного ускоряется.
Врежешься в стену или в собственный хвост — конец. Рекорд сохраняется в браузере.

## Как запустить у себя

Скачай `index.html` и открой двойным щелчком — этого достаточно, интернет не нужен.

## Что внутри

Чистые HTML, CSS и JavaScript, отрисовка на `<canvas>`. Весь код — в `index.html`.
